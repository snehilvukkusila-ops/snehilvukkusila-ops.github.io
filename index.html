Test apps for comparing documentation tools

Synthetic probe apps and two open-source apps (MIT), hosted as static sites so documentation tools can be pointed at a public URL. Nothing here is a real product, and no data is stored or sent anywhere.

  • Probe Pages - synthetic: team list, invite form, settings, a two-step report wizard and a workspace policy page.
  • Probe Fields - synthetic: tasks table, a new-task form with many field types, profile and about pages.
  • Probe Guide - synthetic: goals list, new and edit goal pages, and a read-only reports page.
  • shadcn-admin - open source admin dashboard (MIT, by satnaing), rebuilt to be served under /shadcn-admin/.
  • TailAdmin React - open source admin dashboard template (MIT, by TailAdmin), rebuilt to be served under /tailadmin/.

Forms are static and do not submit anywhere. See the repository README for how each app was built and what differs from the originals.
